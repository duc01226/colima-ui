# Project code review rules

> Last scanned: 2026-10-14

Read this before reviewing changes. Start at the actual rule owner and its consumers; distinguish executable gates, documented intent and observed variants. The checks below are source-backed guidance, not a claim that the current application passed a runtime audit.

## Backend contracts to preserve

- Trace HTTP, IPC and direct CLI/service callers together. Shared commands own exec/run guards, but direct-route and adapter paths exist. HTTP Colima stop/delete do not perform all native state cleanup/activity effects (`src-tauri/src/commands/containers.rs:695`, `src-tauri/src/routes/k8s.rs:15`, `src-tauri/src/routes/instances.rs:28`, `src-tauri/src/commands/colima.rs:313`).
- Preserve public health/protected operations and the explicit query-token allowlist; retain desktop IPC/browser-fragment token handoff and the absence of an HTTP token endpoint. Auth tests protect the router/token rules (`src-tauri/src/api_server.rs:288`, `src-tauri/src/api_server.rs:430`, `src-tauri/src/api_server.rs:442`, `src-tauri/src/auth.rs:15`, `src-tauri/src/auth.rs:49`, `src-tauri/src/auth.rs:203`, `src/lib/api/client.ts:223`).
- Preserve stable error-code serialization, redacted technical/command context and frontend localization ownership. Keep profile/default-name and caller-selected-base path-confinement semantics; typed shell text is a different guard (`src-tauri/src/error.rs:22`, `src-tauri/src/error.rs:303`, `src-tauri/src/error.rs:320`, `src-tauri/src/error.rs:342`, `src-tauri/src/validation.rs:158`, `src-tauri/src/validation.rs:193`, `src-tauri/src/validation.rs:281`).
- Covered mutations record actual outcomes without secrets. Update the named activity contract lists when extending them; these sensors do not discover every future command. Preserve failure reason and shared self-heal verb spelling (`src-tauri/src/commands/activity_coverage.rs:42`, `src-tauri/tests/activity_records_every_mutating_command.rs:29`, `src-tauri/src/commands/activity.rs:560`, `src-tauri/src/commands/activity_coverage.rs:161`).
- Self-heal must retain advisory-only actions, Suggest fallback, kill-switch-before-action, quota outcome accounting and crash-window reset (`src-tauri/src/commands/self_heal.rs:610`, `src-tauri/src/commands/self_heal.rs:1040`, `src-tauri/src/commands/self_heal.rs:1049`, `src-tauri/src/commands/self_heal.rs:1057`, `src-tauri/src/commands/self_heal.rs:1084`).
- Preserve unknown Colima YAML keys/expected-mtime refusal and distinguish a SQLite lock from a transaction. File-output transfer success follows scratch rename; cancellation intent precedes kill. Lossy channels require the owner's recovery strategy (`src-tauri/src/commands/colima_config.rs:614`, `src-tauri/src/commands/colima_config.rs:796`, `src-tauri/src/commands/ai_chat.rs:183`, `src-tauri/src/commands/activity.rs:407`, `src-tauri/src/commands/file_transfer.rs:409`, `src-tauri/src/commands/file_transfer.rs:769`, `src-tauri/src/routes/misc.rs:83`).

Read `docs/backend-patterns-reference.md` when reviewing request/storage/async changes and `docs/domain-entities-reference.md` when reviewing identity or lifecycle rules. Do not assume timeout means cancellation or optional writer means durable persistence (`src-tauri/src/commands/runtime.rs:55`, `src-tauri/src/commands/metrics_collector.rs:89`).

## Frontend contracts to preserve

- Reuse typed props/callbacks and matching shared owner contracts; feature actions stay with their owner. Page state is not a URL router, and Terminal has a deliberate retained mount lifetime (`src/components/RowActions.svelte:27`, `src/components/settings/SettingsSection.svelte:8`, `src/App.svelte:75`, `src/App.svelte:193`).
- Trace both API-list mapping and event normalization when changing a field. Runtime detection belongs to `env.ts`; ordinary requests use typed API wrappers. Metrics' SSE-in-both-modes contract is separate (`src/lib/env.ts:1`, `src/lib/api/client.ts:103`, `src/lib/api/docker.ts:7`, `src/lib/dataPoller.ts:86`, `src/lib/api/metrics.ts:65`).
- Preserve loading versus loaded-empty/capability distinctions, per-operation failure attribution, IME-safe send, and accepted-transfer handoff to app-lifetime notifications. Unknown expired outcomes must not become inferred success (`src/store.svelte.ts:19`, `src/store/capabilities.svelte.ts:63`, `src/lib/errorReporter.ts:23`, `src/components/AiChatPanel.svelte:133`, `src/components/transfer/TransferDialog.svelte:181`, `src/store/notifications.svelte.ts:357`).
- Check resource acquisition and teardown at the actual component/adapter, including late async acquisition. Existing data-poller native listeners do not establish universal unlisten cleanup (`src/pages/TerminalInstance.svelte:102`, `src/pages/TerminalInstance.svelte:160`, `src/lib/transferEvents.ts:65`, `src/lib/dataPoller.ts:145`).
- Put shared CSS in its owner module; index.css remains imports-only. Verify accessible names/keyboard/focus behavior for the changed control. Svelte/ESLint accessibility warnings are filtered, so green lint is not accessibility proof (`src/index.css:1`, `src/components/RowActions.svelte:43`, `src/components/settings/ModelPicker.svelte:95`, `src/components/notifications/NotificationPanel.svelte:61`, `svelte.config.js:1`, `eslint.config.js:124`).

Read `docs/frontend-patterns-reference.md` for form/lifetime variants, `docs/design-system/README.md` for tokens/visual owners and `docs/topology-design-philosophy.md` before changing graph actions. Source observations describe their owner scope; do not promote one form's validation or draft retention to a universal policy.

## Executable quality gates and limits

Package/CI gates are `npm run lint`, `npm run typecheck`, `npm run check`, `npm run check:tokens`, `npm run check:i18n`, `npm test` and `npm run lint:rust`. Rust lint invokes Clippy across all targets/features with `-D warnings`. CI separately runs `cargo test --lib` on native Linux; that lane does not run `src-tauri/tests` (`package.json:13`, `package.json:19`, `.github/workflows/ci.yml:31`, `.github/workflows/ci.yml:95`, `.github/workflows/ci.yml:104`).

The pre-push hook selects installed pnpm with its lockfile, otherwise npm, and runs frontend gates plus Clippy. Its explicit SKIP_LINT_GATES branch means hook presence is not proof every push ran checks. Package prepare installs hooks through a Bash script; native Windows support for that script is not established (`.githooks/pre-push:14`, `.githooks/pre-push:19`, `.githooks/pre-push:37`, `package.json:23`, `scripts/setup-hooks.sh:2`).

CSS-token checking catches undefined custom-property reads, with an exception for runtime column widths. Localization checking compares locale keys to English and recognizes a limited literal-call syntax; neither sensor validates rendered styles, accessibility or translation quality. ESLint ignores docs/framework/generated paths and intentionally disables some Svelte/a11y rules (`scripts/check-css-tokens.mjs:12`, `scripts/check-css-tokens.mjs:29`, `scripts/check-i18n-keys.mjs:55`, `scripts/check-i18n-keys.mjs:81`, `eslint.config.js:20`, `eslint.config.js:104`).

Keep the metrics collector independent from paid-build modules; a library source sensor pins that boundary (`src-tauri/src/commands/metrics_collector.rs:653`). Choose real boundary evidence deliberately: ignored tests and prerequisite early returns can produce green harness results without exercising Docker/Trivy. Read `docs/integration-test-reference.md` before selecting those commands (`src-tauri/tests/security_scan_against_trivy.rs:28`, `src-tauri/tests/security_score_against_corpus.rs:49`).

Review failures against the governing owner and actual consumers. Current references name regression guards and their limits; historical manual examples, source sensors and a successful exit alone do not establish full behavior coverage.
