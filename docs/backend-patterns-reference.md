# Backend patterns

> Last scanned: 2026-10-14

Read this before changing Rust requests, validation, storage or background work. Trace the actual entry point and consumer: desktop IPC, HTTP and standalone CLI share some owners but have different side effects. This guide records source behavior; it does not establish runtime verification.

## Request and rule ownership

HTTP registration lives in `src-tauri/src/api_server.rs:53`; native registration in `src-tauri/src/lib.rs:142`. Container routes usually extract input and delegate to commands, where shared exec/run checks live. Kubernetes also has direct route-owned CLI logic. CLI and self-heal use service/adapter paths, while GUI commands can use runtime helpers directly; there is no universal commands → services → adapters pipeline (`src-tauri/src/routes/containers.rs:23`, `src-tauri/src/commands/containers.rs:695`, `src-tauri/src/routes/k8s.rs:15`, `src-tauri/src/bin/cli.rs:274`, `src-tauri/src/commands/self_heal.rs:692`).

Trace variants before moving a rule. HTTP Colima stop/delete call CLI-only functions; desktop variants additionally clear/suppress Docker state, emit events and record activity. HTTP container listing uses CLI; native listing tries Bollard then falls back (`src-tauri/src/routes/instances.rs:28`, `src-tauri/src/commands/colima.rs:251`, `src-tauri/src/commands/colima.rs:313`, `src-tauri/src/routes/containers.rs:11`, `src-tauri/src/commands/containers.rs:175`).

| Boundary | Owner and action-changing contract |
| --- | --- |
| Errors | `ColimaError` has stable snake_case codes and redacted technical context; frontend owns localization. Preserve known command/exit context with `error_from_output` where process output is available (`src-tauri/src/error.rs:22`, `src-tauri/src/error.rs:35`, `src-tauri/src/error.rs:60`, `src-tauri/src/helpers.rs:60`). |
| HTTP responses | Ordinary handlers use `ApiResponse<T>`; `err` currently returns 500 even for validation. Auth rejection is bare 401. Stream/SSE endpoints have separate contracts; stringifying a known error can lose optional context (`src-tauri/src/helpers.rs:21`, `src-tauri/src/helpers.rs:43`, `src-tauri/src/auth.rs:153`, `src-tauri/src/routes/instances.rs:23`). |
| HTTP auth | Health is public; operation router has auth middleware. Bearer is normal; query-token auth is explicitly allowlisted for events and pod log streams. Desktop token handoff is IPC; browser consumes an out-of-band URL fragment. There is no HTTP token endpoint (`src-tauri/src/api_server.rs:288`, `src-tauri/src/api_server.rs:298`, `src-tauri/src/auth.rs:49`, `src-tauri/src/auth.rs:74`, `src/lib/api/client.ts:223`). |
| Names and paths | Reuse profile/resource guards, including empty profile meaning default where `ensure_valid_profile` is used. Host writes use caller-selected-base `assert_path_within`, resolving existing paths or parents and failing closed; container-side paths use separate policy (`src-tauri/src/validation.rs:103`, `src-tauri/src/validation.rs:158`, `src-tauri/src/validation.rs:169`, `src-tauri/src/validation.rs:193`). |
| Typed exec and run | Shared exec checks ID and command text; run checks banned Docker flags/root-bind forms before execution and records environment counts rather than values. Literal lifecycle argv and separate adapters do not automatically inherit these checks (`src-tauri/src/commands/containers.rs:695`, `src-tauri/src/commands/containers.rs:738`, `src-tauri/src/commands/containers.rs:755`, `src-tauri/src/commands/containers.rs:807`). |

Sandbox classification is a separate policy owner. Ordinary safe/approved execution reclassifies; approved execution still refuses Banned. The protected `execute_stream` HTTP handler directly spawns split argv rather than using those executors, so sandbox coverage must be traced per path (`src-tauri/src/commands/shell_sandbox.rs:113`, `src-tauri/src/commands/shell_sandbox.rs:253`, `src-tauri/src/commands/shell_sandbox.rs:275`, `src-tauri/src/api_server.rs:279`, `src-tauri/src/routes/kb.rs:109`). Read `docs/ai.md` when changing AI tool/approval behavior.

## Storage and schema evolution

Application persistence is direct `rusqlite` SQL in command owners. Knowledge-bank setup installs a mutex-protected `knowledge.db` connection before API/background work; chat, settings/presets, articles, terminal metadata and self-heal share it. Activity owns a separate lazily opened `activity.db` (`src-tauri/src/lib.rs:97`, `src-tauri/src/commands/knowledge_bank.rs:7`, `src-tauri/src/commands/self_heal.rs:263`, `src-tauri/src/commands/activity.rs:293`).

Schema setup uses owner-local idempotent DDL. Chat's guarded migration adds conversation identity and adopts retained history; schema triggers maintain memory/article FTS indexes. A connection lock does not make multiple SQL statements transactional: chat save/delete are sequential under a guard, while activity retention commits its age/count deletes in one transaction (`src-tauri/src/commands/knowledge_bank.rs:148`, `src-tauri/src/commands/knowledge_bank.rs:216`, `src-tauri/src/commands/ai_chat.rs:123`, `src-tauri/src/commands/ai_chat.rs:183`, `src-tauri/src/commands/activity.rs:407`).

Read `src-tauri/src/commands/knowledge_bank.rs` when evolving shared schema/settings/presets; read `src-tauri/src/commands/ai_chat.rs` for thread behavior and `src-tauri/src/commands/kb_articles.rs` for offline Help/search. Article replacement is gated by a greater shipped version; read `docs/seed-test-data-reference.md` before changing startup content (`src-tauri/src/commands/kb_articles.rs:169`).

Record machine actions through `activity::record`. Its owner redacts detail, tolerates storage failure and opportunistically prunes to 7 days/500 rows after writes; these are periodic pruning bounds, not an immediate cap. Live engine/VM state remains external authority. The app data helper uses nonempty HOME or `/tmp`, plus `.colima-ui`; exports, Colima files and autostart have other locations (`src-tauri/src/commands/activity.rs:361`, `src-tauri/src/commands/activity.rs:368`, `src-tauri/src/commands/activity.rs:378`, `src-tauri/src/commands/activity.rs:407`, `src-tauri/src/path_util.rs:65`, `src-tauri/src/commands/autostart.rs:26`).

Security findings use a digest-keyed process cache with a 6-hour TTL; Trivy owns its vulnerability database. Colima YAML editing preserves unmanaged keys, checks expected mtime, backs up and fsyncs/renames a sibling temporary file. File-output transfers and SBOM also publish scratch output by rename; activity/diagnostic exports use direct writes, so choose the actual owner's contract (`src-tauri/src/commands/security_scan.rs:275`, `src-tauri/src/commands/security_scan.rs:426`, `src-tauri/src/commands/security_scan.rs:553`, `src-tauri/src/commands/colima_config.rs:509`, `src-tauri/src/commands/colima_config.rs:614`, `src-tauri/src/commands/activity_feed.rs:289`, `src-tauri/src/commands/diagnostics.rs:418`).

## Background work and delivery

DockerState owns the daemon event stream, reconnect and cache invalidation. Raw lifecycle publication precedes display debounce so self-heal can count individual events. The raw broadcast has capacity 512 and can lag; SSE display has capacity 64, reports `stream-lagged` and has no replay (`src-tauri/src/docker_state.rs:171`, `src-tauri/src/docker_events.rs:33`, `src-tauri/src/docker_events.rs:75`, `src-tauri/src/sse.rs:6`, `src-tauri/src/routes/misc.rs:83`).

Dashboard state uses desktop events or browser SSE; metrics use named-topic SSE in both modes. Explicit `metrics.sample` subscriptions activate the collector; topicless SSE clients do not. Optional `MetricWriter` receives batches before display publication, but no production writer registration was found. Enabled resource-saver polling is independent of collector gating (`src/lib/dataPoller.ts:145`, `src/lib/api/metrics.ts:65`, `src-tauri/src/sse.rs:62`, `src-tauri/src/commands/metrics_collector.rs:93`, `src-tauri/src/commands/metrics_collector.rs:471`, `src-tauri/src/commands/system.rs:550`).

Keep recovery appropriate to the data: state consumers refetch; chart consumers show gaps; transfer consumers reconcile against registry snapshots (`src-tauri/src/sse.rs:154`, `src/lib/api/metrics.ts:96`, `src/pages/Activity.svelte:63`, `src/lib/transferNotifications.ts:62`).

| Long-lived owner | Contract |
| --- | --- |
| Transfers | `transfer_registry` owns readable identity/status and destination claims; `streaming_cmd` owns OS children/scratch output; `commands::file_transfer` owns validation/argv/events. Register before spawn; file-output success follows rename, other jobs settle after successful process completion. Retain terminal outcomes for 60 seconds and record cancellation intent before kill, including before spawn. Destination equality is stored PathBuf equality, not a cross-process lock (`src-tauri/src/transfer_registry.rs:120`, `src-tauri/src/transfer_registry.rs:168`, `src-tauri/src/transfer_registry.rs:297`, `src-tauri/src/commands/file_transfer.rs:324`, `src-tauri/src/commands/file_transfer.rs:346`, `src-tauri/src/commands/file_transfer.rs:377`, `src-tauri/src/streaming_cmd.rs:467`). |
| Processes | Runtime's async wait timeout does not provide child cancellation. Streaming commands keep cancellation handles; Unix uses process groups, other platforms fall back to child kill. File stdout is streamed, but stderr/ByLine are not universally memory-bounded (`src-tauri/src/commands/runtime.rs:55`, `src-tauri/src/streaming_cmd.rs:121`, `src-tauri/src/streaming_cmd.rs:267`, `src-tauri/src/streaming_cmd.rs:413`). |
| Interactive terminals | One SessionManager owns PTYs via Tauri IPC Channel; HTTP shell routes are removed. Reusing an ID closes/replaces the old PTY; new sessions cap at 16, idle sessions reap after 30 minutes, UI teardown/app exit close children (`src-tauri/src/api_server.rs:284`, `src-tauri/src/terminal_session.rs:219`, `src-tauri/src/terminal_session.rs:454`, `src-tauri/src/lib.rs:363`, `src/pages/TerminalInstance.svelte:160`). |
| Self-heal | Executor checks kill switch → Suggest/auto capability → quota → perform. Database/quota errors fail closed; only Executed/Failed spend quota. Advisory actions cannot auto-run. These checks do not establish atomic reservation across concurrent firings (`src-tauri/src/commands/self_heal.rs:110`, `src-tauri/src/commands/self_heal.rs:240`, `src-tauri/src/commands/self_heal.rs:566`, `src-tauri/src/commands/self_heal.rs:610`). |

Transfer SSE emission is unconditional; Tauri emission requires the initiating IPC AppHandle. Announcements use a fixed parameterless feed request; the client owns scheduling and checks the off switch first. Read `docs/telemetry.md` when changing outbound data (`src-tauri/src/commands/file_transfer.rs:57`, `src-tauri/src/commands/announcements.rs:95`, `src/lib/announcements.ts:268`).

Read `docs/domain-entities-reference.md` for identities and invariants, `docs/integration-test-reference.md` for boundary-test isolation, and `docs/code-review-rules.md` for review gates. Preserve transport-specific validation, transaction, delivery and cleanup contracts at their actual owners.
