# Resource concepts and ownership

> Last scanned: 2026-10-14

Read this before changing resource identity, lifecycle, safety rules or persisted application choices. Docker, Colima and Lima own live resources; application stores and histories are representations. The source establishes business rules without a required entity hierarchy or DDD layer model.

## Concepts and invariants

| Concept | Identity, authority and rule owner |
| --- | --- |
| Colima profile | Empty profile selects default at the guarded command boundary. Names affect both argv and paths. For command/tray start, existing `colima.yaml` wins over wizard defaults; resource flags are emitted only on first start. Separate VM adapter start constructs its own flags (`src-tauri/src/validation.rs:103`, `src-tauri/src/validation.rs:158`, `src-tauri/src/commands/colima.rs:101`, `src-tauri/src/commands/colima.rs:131`, `src-tauri/src/adapters/colima.rs:56`). |
| Container | Runtime-owned identity/state. Shared exec checks ID/text; shared run rejects prohibited flags/root-bind forms before execution and logs environment counts. Separate literal lifecycle/adapter paths have their own contracts (`src-tauri/src/commands/containers.rs:695`, `src-tauri/src/commands/containers.rs:738`, `src-tauri/src/commands/containers.rs:755`, `src-tauri/src/commands/containers.rs:807`). |
| Transfer job | Registry-owned ID/status/destination claim, separate from OS process identity. Starting/Running → Success/Failed/Cancelled; cancellation can settle before spawn. File-output success follows rename; other jobs settle after successful process completion. Terminal entries remain readable for 60 seconds; state is not persisted across app exit (`src-tauri/src/transfer_registry.rs:35`, `src-tauri/src/transfer_registry.rs:120`, `src-tauri/src/transfer_registry.rs:168`, `src-tauri/src/commands/file_transfer.rs:346`, `src-tauri/src/commands/file_transfer.rs:377`, `src-tauri/src/commands/file_transfer.rs:409`, `src-tauri/src/streaming_cmd.rs:467`). |
| Terminal session | UI session ID keys a live PTY; reuse closes/replaces its child. SQLite history records kind/target metadata rather than transcript. Output uses native IPC Channel (`src-tauri/src/terminal_session.rs:203`, `src-tauri/src/terminal_session.rs:219`, `src-tauri/src/commands/terminal.rs:20`, `src/lib/terminal-transport.ts:80`). |
| Metric sample | Collector owns timestamped instance/container attribution. SSE is lossy display; direct writer is an optional sink with no production registration found (`src-tauri/src/commands/metrics_collector.rs:56`, `src-tauri/src/commands/metrics_collector.rs:89`, `src-tauri/src/commands/metrics_collector.rs:471`). |
| Self-heal rule/firing | Row ID plus unique trigger; trigger/action are fixed while mode, threshold, quota and enabled can change. Suggest is default. Advisory actions remain Suggest; kill switch precedes mode/quota/action. Executed/Failed spend per-rule hourly quota; blocked/advice outcomes do not (`src-tauri/src/commands/self_heal.rs:110`, `src-tauri/src/commands/self_heal.rs:240`, `src-tauri/src/commands/self_heal.rs:276`, `src-tauri/src/commands/self_heal.rs:360`, `src-tauri/src/commands/self_heal.rs:429`, `src-tauri/src/commands/self_heal.rs:610`). |
| Activity action | Stable target identity differs from display name; actor distinguishes User/App and outcome distinguishes success/failure/denial/cancellation. Best-effort recording redacts detail and cannot fail the original action (`src-tauri/src/commands/activity.rs:96`, `src-tauri/src/commands/activity.rs:120`, `src-tauri/src/commands/activity.rs:163`, `src-tauri/src/commands/activity.rs:362`, `src-tauri/src/commands/activity.rs:378`). |

Trigger metadata is not proof a detector runs: VM-unresponsive metadata has no observed firing producer; DiskFull uses reclaimable-byte heuristics. The self-heal gate/log path does not establish atomic concurrent quota reservation (`src-tauri/src/commands/self_heal.rs:351`, `src-tauri/src/commands/self_heal.rs:566`, `src-tauri/src/commands/self_heal.rs:610`, `src-tauri/src/commands/self_heal.rs:914`).

## Representations and boundary flows

DockerState caches daemon reads, republishes after reconnect and clears stale state on verified daemon loss. Colima instance display comes from the shared filesystem/status reader, honoring COLIMA_HOME; config GiB values become byte values in the response. Desktop poller and SSE publisher derive separate views from that same reader (`src-tauri/src/docker_state.rs:152`, `src-tauri/src/docker_state.rs:242`, `src-tauri/src/instance_reader.rs:50`, `src-tauri/src/instance_reader.rs:98`, `src-tauri/src/poller.rs:44`, `src-tauri/src/sse.rs:266`).

Frontend stores hold display copies. API list mapping and pushed-state normalization are separate paths; graph/list navigation converts resource identity before handoff. Read `docs/frontend-patterns-reference.md` when changing those mappings and `docs/topology-design-philosophy.md` when changing graph interactions (`src/lib/api/docker.ts:7`, `src/lib/dataPoller.ts:86`, `src/lib/normalizers.ts:12`, `src/lib/topology-link.ts:23`).

Transfer events are fast updates; registry list is the recovery authority after reload/stream gaps. If a terminal outcome has expired, the UI marks it ended/unknown rather than inventing success. Registry destination equality does not imply canonical aliases or cross-process exclusion (`src/lib/transferNotifications.ts:62`, `src/store/notifications.svelte.ts:357`, `src-tauri/src/transfer_registry.rs:120`).

HTTP and native wrappers can differ in state cleanup/activity side effects: HTTP Colima stop/delete are CLI-only, and HTTP self-heal configuration calls raw data functions while desktop wrappers also record activity. Read the caller, not just a shared type or operation name (`src-tauri/src/routes/instances.rs:28`, `src-tauri/src/commands/colima.rs:313`, `src-tauri/src/routes/self_heal.rs:32`, `src-tauri/src/commands/self_heal.rs:981`).

## Persisted choices and relationships

The shared `knowledge.db` connection supports diagnostic knowledge, settings/presets, chat, articles, terminal metadata and self-heal. `activity.db` independently owns action history. Relationships below are enforced by application code unless a schema constraint is cited; do not infer SQL foreign keys (`src-tauri/src/commands/knowledge_bank.rs:7`, `src-tauri/src/commands/knowledge_bank.rs:27`, `src-tauri/src/commands/self_heal.rs:263`, `src-tauri/src/commands/activity.rs:293`).

| Persisted concept | Behavior and owner |
| --- | --- |
| Solutions and memories | Solutions have integer identity/feedback counters and form short diagnostic context. Memories have text identity and FTS search maintained by schema triggers (`src-tauri/src/commands/knowledge_bank.rs:164`, `src-tauri/src/commands/knowledge_bank.rs:449`, `src-tauri/src/commands/knowledge_bank.rs:578`, `src-tauri/src/commands/knowledge_bank.rs:649`). |
| Offline Help article | Separate from solutions; unique `(slug, locale)`, locale normalization/English fallback, replacement only when shipped version increases (`src-tauri/src/commands/knowledge_bank.rs:127`, `src-tauri/src/commands/kb_articles.rs:153`, `src-tauri/src/commands/kb_articles.rs:169`, `src-tauri/src/commands/kb_articles.rs:208`). |
| Chat thread/message | Text IDs; missing conversation uses default. Save ensures parent, upserts message and updates recency. Deletes are conversation-scoped; default thread is retained. Locking serializes local access but save/delete are not multi-statement transactions (`src-tauri/src/commands/ai_chat.rs:123`, `src-tauri/src/commands/ai_chat.rs:146`, `src-tauri/src/commands/ai_chat.rs:183`, `src-tauri/src/commands/ai_chat.rs:203`). |
| Settings/preset/snapshot | Settings upsert strings by key; presets store opaque JSON by caller ID. Snapshots associate saved JSON with preset/profile/time, rather than owning current engine state (`src-tauri/src/commands/knowledge_bank.rs:777`, `src-tauri/src/commands/knowledge_bank.rs:895`, `src-tauri/src/commands/knowledge_bank.rs:944`). |
| Heal/action timeline | Heal log links rule/resource identity in application code; activity feed combines it with independent action history and exposes failed sources through `partial`. A timeline is evidence about actions, not current runtime authority (`src-tauri/src/commands/self_heal.rs:287`, `src-tauri/src/commands/activity_feed.rs:140`). |

Colima configuration remains an external tool-owned YAML document: edit managed fields while retaining unknown keys and refusing stale mtime. Security scan results are a digest-keyed process cache; Trivy owns its DB and SBOM is an export, not persisted audit history (`src-tauri/src/commands/colima_config.rs:614`, `src-tauri/src/commands/security_scan.rs:275`, `src-tauri/src/commands/security_scan.rs:426`, `src-tauri/src/commands/security_scan.rs:553`).

Read `docs/backend-patterns-reference.md` for request/storage/async contracts and `docs/seed-test-data-reference.md` for fixture/startup-content ownership. Preserve the distinction between runtime authority, application choices, transient job state and historical observations.
