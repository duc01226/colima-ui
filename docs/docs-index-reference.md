## Ownership and relationships

`README.md` links to `docs/`; `docs/README.md` links the technical guides. `docs/ai.md` points to `external_skill/SKILL.md`, which owns discovery of its bundled references. `docs/project-config.json` preserves the technical guides as manual references, selects source-derived references for automated scanning and sets `docs/` as the project-reference root. The index and lessons are always-on inputs independent of that selection. Framework implementation lives under `.claude/`; host projections are generated by the owning context pipeline.

Canonical feature specs have not been established. Create them only for an accepted capability scope or an existing canonical owner. Runtime review outputs are candidate evidence until explicitly accepted; setup does not create an accepted baseline.
